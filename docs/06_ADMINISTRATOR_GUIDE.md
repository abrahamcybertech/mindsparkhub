# MindSpark Hub Official Platform: Administrator Guide

## 1. Introduction for Non-Technical Staff

Welcome to the MindSpark Hub Administrator Dashboard. This portal enables executive leaders, coordinators, and editorial personnel to manage the public web platform with confidence, clarity, and security.

Every control in this system is designed around real operational facts. When an area shows zero, it means zero items exist; no placeholder or simulated statistics are used.

---

## 2. Accessing the Dashboard

1. Navigate to the secure URL: `/admin`
2. Enter your registered institutional email address and secure password (minimum 12 characters).
3. **Multi-Factor Authentication (MFA):** When prompted, open your authenticator mobile application (Google Authenticator, Microsoft Authenticator, or Aegis) and enter the current 6-digit code.
4. If you lose access to your authenticator, use one of your stored single-use backup recovery codes.

---

## 3. Managing Operational Modules

### 3.1 Programmes & Events
- **Viewing Programmes:** Access the three core impact vehicles: Secondary Schools Invasion (SSI), Campus Sparking (CS), and Community Enlightenment (CE).
- **Scheduling New Events:**
  1. Click **Schedule New Event**.
  2. Select the target programme (SSI, CS, or CE).
  3. Enter the venue, starting date and time, concluding date and time, and event description.
  4. Note that Programme Managers create events in **Draft** or **Pending Approval** status.
  5. An **Administrator** or **Super Administrator** must review and click **Approve & Publish** before the event appears on public pages.

### 3.2 Gallery Management & Safeguarding
- **Uploading Real Photography:** Select JPEG, PNG, or WebP images from verified outreach moments.
- **Children Safeguarding Gate:** If the photograph contains secondary school students or identifiable minors:
  - Check the box **Identifiable Minor Depicted**.
  - Provide the institutional consent reference code (e.g. `FGCW-SSI-CONSENT-2026-01`).
  - An Administrator must verify the consent document before clicking **Publish**.
- **One-Click Takedown:** If a school or guardian requests removal of a photograph, navigate to the gallery list and click **Emergency Takedown**. The photo will instantly vanish from public view.

### 3.3 Insights & Articles
- Draft educational articles, skills acquisition guides, academic excellence methodologies, and community reports.
- Preview your draft to see how it appears to visitors.
- Published articles will automatically calculate estimated reading time and generate social preview cards.

### 3.4 Applications & Inquiries
- View incoming applications for joining the organization, volunteering, mentoring, partnering, or general inquiries.
- Each submission is assigned a unique reference code (e.g. `MSH-2026-8419`) that the applicant also received.
- Add internal staff notes and update the review status (`New`, `Under Review`, `Contacted`, `Archived`).

### 3.5 System Audit Logs
- Every administrative action (logins, content edits, approvals, takedowns, exports) is permanently recorded in the immutable audit log.
- Logs include the timestamp, user, role, IP address, and cryptographic security verification hash.

## 4. Security Rules for Staff
- Never share your dashboard password or multi-factor recovery codes.
- Always sign out when using a shared computer.
- Ensure all uploaded photos reflect authentic MindSpark Hub activities.
- Respect all child safeguarding guidelines.
